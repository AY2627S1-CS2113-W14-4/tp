# StockHolm

StockHolm is a command-line app for managing several inventories, such as a warehouse and a shop, from the keyboard.
Stock enters and leaves an inventory through import, export and transfer orders that are approved and delivered, so
every change to stock goes through a recorded order.

**What you can do with it:**

* Keep any number of inventories, each with its own items, types and decimal counts (e.g. `2.5` kg).
* Move stock with orders that go through approval and delivery, and reject or cancel them along the way.
* See stock levels anywhere, search items across inventories, and set minimum stock levels so StockHolm tells you
  what to reorder.
* Keep working offline: data is saved automatically to human-editable files, with backups if a file is damaged.

**Get started:** install Java 25, download `stockholm.jar` from the
[latest release](https://github.com/AY2627S1-CS2113-W14-4/tp/releases), and run `java -jar stockholm.jar` in a
terminal. Type `help` to see every command.
